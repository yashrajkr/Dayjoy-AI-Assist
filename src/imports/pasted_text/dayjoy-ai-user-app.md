You are a senior SaaS UI/UX designer, enterprise AI product designer, ChatGPT-style product designer, and internal admin dashboard designer.

Create a complete production-level UI for a platform called:

Dayjoy AI Assistant

Important concept:
This product has TWO separate interfaces:

1. User-facing AI app
This should work like ChatGPT, where customers, distributors, and employees ask questions and get Dayjoy-related answers.

This works behind the screen, where Dayjoy employees and admins upload product data, approve knowledge, manage users, review AI answers, handle support tickets, and improve the AI knowledge base.

Do not mix both apps into one confusing screen.

IMPORTANT USER FLOW

Create separate flows:

FLOW 1: Customer asks product question
Customer opens Dayjoy GPT → asks question → AI searches approved data → AI gives safe answer → shows source citation → user can ask support.

FLOW 2: Distributor uses coach
Distributor opens Dayjoy GPT → asks objection handling question → AI gives ethical reply → distributor copies message → analytics records usage.

FLOW 3: Employee uploads data
Employee opens Admin App → uploads product brochure → AI extracts information → status becomes pending → admin reviews → approves → data becomes available in user app.

FLOW 4: Admin approves knowledge
Admin opens Approval Queue → reviews extracted content → checks source and safety → clicks Approve & Index → AI can now use that data.

FLOW 5: Management reviews insights
Management opens dashboard → sees top asked products, knowledge gaps, risky queries → exports report → gives action to team.

IMPORTANT DESIGN RULES

- User app should feel like ChatGPT.
- Admin app should feel like Shopify Admin / Zendesk / Microsoft Copilot Studio.
- Keep user app simple.
- Keep admin app powerful and data-heavy.
- Do not show admin tools to customers.
- Do not show internal approval tools in user-facing chat.
- Clearly separate “Ask AI” from “Manage AI Knowledge”.
- Every AI answer should show safety and source confidence.
- Every admin data item should show approval status.
- Every uploaded document should require review before becoming active knowledge.
